# KnaveShell

KnaveShell is the repository for Villain, a Wayland compositor. Keep repository
guidance and project documentation accurate as the implementation grows.

## Repository expectations

- Preserve the existing project direction and avoid documenting commands or
  features that are not present in the repository.
- Update `README.md` when the build, run, test, or contribution workflow
  changes.
- Prefer small, focused changes that are easy to review.

## Commits and Pull Requests

- Use conventional commits
- Commit after every meaningful change
- Always create a new branch when you start working on a task.
- Always Squash and Merge
